# TendorNet

Website project TendorNet dengan frontend HTML/CSS/Bootstrap dan backend PHP.

## Live Demo

GitHub Pages diarahkan ke folder `docs/`.

Setelah repository di-push ke GitHub:
**Settings → Pages → Deploy from a branch → pilih branch utama → folder `/docs`.**

## Demo

- Home
- Produk: Internet + TV, TV, Games
- Promo
- Berita
- Bantuan / Contact Us
- Info TendorNet
- FAQ
- Demo checkout

> Demo GitHub Pages bersifat static. Fitur PHP, database, login asli, transaksi, dan logout asli tetap berada di source project dan perlu dijalankan menggunakan PHP + database (misalnya XAMPP).

## Struktur

- `frontend/` — source frontend PHP asli
- `backend/` — source backend PHP
- `tendornet.sql` — database
- `docs/` — static frontend untuk GitHub Pages
